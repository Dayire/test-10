# Requests from the first integration pass (I0)

The integrator owns the frozen engine files and P's finished files; these are changes it found in files other
packages own. Each entry: file, change, reason, test.

## 1. `src/game/bridge.js` (L): one mesh for the rope ladder

- **Change.** Build `RopeLadder`'s two ropes and its rungs as one merged geometry (they share the `woodDark` /
  `ropeMat` split today: two meshes at most, or one with vertex colours), keeping the group's `scale.y` unroll and
  its sway.
- **Reason.** It is 16 meshes of 24 triangles: 16 draws in the main pass and 16 in every shadow pass that sees it
  (the courtyard and the balcony, Chapter I's two heaviest spots). The shadow policy now treats a caster that only
  sways (within 2 cm) as static, so on low and medium the rolled-up ladder stops casting; unrolled it still costs
  32 draws a frame on low.
- **Test.** `node tools/perf.mjs --tiers low` at the courtyard and the balcony: about 15 fewer calls per frame once
  the ladder is down; the souk bot and negatives pass.

## 2. `src/game/boot.js` (U): the session surface in the chapter's bake

- **Change.** Drop the separate `await world.bake(SESSION_SURFACES)` before `game.initOnce()`: create the boy after
  the first chapter's `world.prebake` has issued its programs, or add `SESSION_SURFACES` to the first load's needs.
- **Reason.** It compiles and draws one surface on its own before anything else can overlap it (about 0.1 s of a
  6.5 s boot on SwiftShader). Small, but it is the only bake left outside the overlapped path.
- **Test.** `node tools/negative.mjs --suite foundation --only "boot budget"`.

## 3. `package.json` (unowned): the whole suite behind one script

- **Change.** Add `"test:all": "npm test && node tools/cycle.mjs && node tools/perf.mjs && node tools/audio-tests.mjs"`.
- **Reason.** Every runner now exits non-zero on any failure (an over-budget spot, a pending check, a page or console
  error), but `npm test` runs only the bot and the negatives. A pipe (`npm test | tail`) reports the last command's
  exit, not the suite's; run it with `set -o pipefail` or without a pipe.
- **Test.** `npm run test:all; echo $?` after breaking any one check.

## 4. `index.html` (U): no script-blocking font stylesheet

- **Change.** Self-host the Cormorant Garamond subset (or load the Google Fonts stylesheet with `media="print"
  onload="this.media='all'"`), so the module script does not wait for a cross-origin stylesheet.
- **Reason.** The `<link rel="stylesheet">` to fonts.googleapis.com blocks the module script until it arrives: on a slow
  or proxied network it added 0-9 s to a boot at random (the foundation suite's boot check measured single boots of 6
  to 16 s until it answered the stylesheet locally). Offline, it fails and the title falls back to the serif stack.
- **Test.** Boot with the network throttled (DevTools "Slow 4G"): `__ready` no longer moves with the font's latency;
  the title still shows Cormorant once the font arrives.
